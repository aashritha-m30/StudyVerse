How it works

1. Vault uploads

When you drop file resources, StudyVerse processes PDFs and raw text client-side, making the text available to the workspace.

2. 100% Privacy

All data analysis and PDF extraction run locally. Your API key communicates directly with Google's API; no third-party backend servers are used.

3. Simulated Demo Mode

If no API key is supplied, StudyVerse defaults to standard local simulation templates so you can check out the layout, interactive quiz interface, flashcard animations, and planner roadmaps.
